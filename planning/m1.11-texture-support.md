# M1.11: 图片/纹理支持

## 目标

实现图片元素和纹理填充，支持在无限画布上绘制图片、图案和渐变。

---

## 输出

- `crates/engine/src/element/image.rs` - 图片元素
- `crates/wasm/src/image_loader.rs` - 图片加载管理
- `crates/wasm/src/canvas.rs` - 图片绘制方法
- `packages/core/src/image.ts` - TypeScript 图片 API
- `www/assets/` - 测试图片资源

---

## 功能

### 1. Image 元素 (Rust)
- Image 结构体（位置、尺寸、URL）
- 支持旋转、缩放变换
- 边界框计算
- 序列化/反序列化

### 2. 图片加载 (WASM/JS)
- HTMLImageElement 缓存
- 异步加载管理
- 加载状态追踪（loading/loaded/error）
- 占位符显示

### 3. Canvas 绘制
- `draw_image()` - 绘制图片
- `draw_image_with_transform()` - 带变换绘制
- 图片裁剪支持
- 透明度支持

### 4. 图案填充 (Pattern)
- `create_pattern()` - 创建图案
- 重复模式（repeat/repeat-x/repeat-y/no-repeat）
- 图案变换
- 应用到矩形/圆形填充

### 5. 渐变填充 (可选)
- 线性渐变（LinearGradient）
- 径向渐变（RadialGradient）
- 多色阶支持
- 渐变角度控制

## API 设计

### Rust API

```rust
// Image 元素
pub struct Image {
    pub props: ElementProps,
    pub size: Vec2,
    pub image_id: String,  // 图片 ID（在 JS 端管理）
    pub crop: Option<Rect>, // 可选裁剪区域
}

impl Image {
    pub fn new(id: ElementId, position: Vec2, size: Vec2, image_id: String) -> Self;
}
```

### WASM API

```rust
// 添加图片元素
#[wasm_bindgen]
pub fn add_image(&mut self, x: f32, y: f32, width: f32, height: f32, image_id: String) -> u64;

// 预加载图片
#[wasm_bindgen]
pub fn preload_image(&mut self, image_id: String, url: String);

// 设置图案填充
#[wasm_bindgen]
pub fn set_pattern_fill(&mut self, element_id: u64, image_id: String, repeat: String);
```

### JavaScript API

```typescript
// 加载图片
await canvas.loadImage('logo', '/assets/logo.png');

// 添加图片元素
const imageId = canvas.addImage(100, 100, 200, 150, 'logo');

// 图案填充
canvas.setPatternFill(rectId, 'pattern-grid', 'repeat');
```

## 技术难点

### 1. 异步加载
- **问题**: 图片加载是异步的，渲染时可能未加载完成
- **方案**: 
  - 维护加载状态（loading/loaded/error）
  - 显示占位符（灰色矩形 + loading 文字）
  - 加载完成后触发重绘

### 2. 图片缓存
- **问题**: 多次使用同一图片应该共享资源
- **方案**:
  - HashMap<String, HtmlImageElement> 缓存
  - 引用计数管理
  - 内存限制策略

### 3. 跨域问题
- **问题**: 外部图片可能有 CORS 限制
- **方案**:
  - 使用 crossOrigin 属性
  - 提供代理选项
  - 明确错误提示

### 4. 大图片性能
- **问题**: 大图片可能导致性能下降
- **方案**:
  - 图片尺寸限制警告
  - 自动缩略图生成
  - 懒加载策略
