# 吸管

从画布上取一个叶子的填充和描边，写到当前选择。不读帧缓冲。

```text
I / 工具栏按钮
        │
        ▼
世界点 ── sample_paint_at
        │     可见叶子；z_index 大的在上，相同则 id 大的在上
        ▼
SampledPaint
        │  fill → 形状填充 + 文本颜色
        │  stroke → 形状和文本的描边
        ▼
可见、未锁定的叶子 ── SetStyleCommand ── 一条历史
```

空白处没有命中。隐藏元素（含被隐藏的祖先）跳过。锁定元素仍然画在画面上，所以可以被采样，但不能被改写。图片没有填充和描边，命中后两个通道都是空，不会把选择上的颜色清掉。缺的通道同样不清掉另一侧已有的颜色。投影不参与采样，也不被这次 `SetStyle` 改写；落在投影上、元素包围盒外的点仍然是空白。

渐变形状采样的是落点上的颜色，不是整段色标。写到选区时收成纯色，原来的渐变被这一条 `SetStyle` 盖住，Ctrl+Z 可以回到渐变。

点到元素后松开指针，工具回到进入吸管之前的那个（空格临时手型不会把这个返回目标冲掉）。点在空白处则留在吸管上。单击已选中的形状走同一条命中，不开始拖动，因此可以把该元素的颜色抄到多选里的其他目标。

快捷键是不带修饰键的 `I`，登记在 `www/shortcuts.js`，`?` 帮助面板会列出。`Shift+I`、`Ctrl/Cmd+I`、`Alt+I` 不触发，V / L / P / R / O / T / H 仍是原来的工具键。
