## 🔧 开发原则

### 1. 测试驱动开发 (TDD)

```
红 → 绿 → 重构 循环

1. 红：编写失败的测试
2. 绿：编写最小代码让测试通过
3. 重构：优化代码，保持测试通过
```

### 2. 测试金字塔

```
           /\
          /  \  E2E 测试 (少量)
         /────\
        /      \  集成测试 (中等)
       /────────\
      /          \  单元测试 (大量)
     /────────────\
```

### 3. 持续集成

```yaml
# .github/workflows/ci.yml
on: [push, pull_request]

jobs:
  test:
    - 单元测试
    - 集成测试
    - 性能测试（回归检测）
    
  coverage:
    - 代码覆盖率报告
    - 覆盖率必须 > 80%
    
  benchmark:
    - 性能基准测试
    - 与上次对比，不能下降 > 5%
```

impl Renderer {
    pub async fn new(canvas: &HtmlCanvasElement) -> Result<Self, RendererError> {
        // 实现初始化逻辑
        let instance = wgpu::Instance::new(wgpu::InstanceDescriptor {
            backends: wgpu::Backends::BROWSER_WEBGPU,
            ..Default::default()
        });
        
        let surface = instance.create_surface_from_canvas(canvas)?;
        let adapter = instance.request_adapter(&wgpu::RequestAdapterOptions {
            power_preference: wgpu::PowerPreference::HighPerformance,
            compatible_surface: Some(&surface),
            force_fallback_adapter: false,
        }).await.ok_or(RendererError::AdapterNotFound)?;
        
        let (device, queue) = adapter.request_device(
            &wgpu::DeviceDescriptor::default(),
            None,
        ).await?;

            format: surface.get_preferred_format(&adapter).unwrap(),
            width: canvas.width(),
            height: canvas.height(),
            present_mode: wgpu::PresentMode::Fifo,
        };
        
        surface.configure(&device, &config);

#[test]
fn test_transform_cascade() {
    // Given: 父子变换
    //   parent: translate(100, 100)
    //   child: translate(50, 50)
    let mut scene = SceneGraph::new();
    let root = scene.root().unwrap();
    
    let parent = scene.add_node(root, Node::Group(GroupNode::new()));
    scene.set_transform(parent, Transform {
        translation: Vec2::new(100.0, 100.0),
        rotation: 0.0,
        scale: Vec2::ONE,
    });
    
    let child = scene.add_node(parent, Node::Shape(ShapeNode::rectangle(50.0, 50.0, 10.0, 10.0)));
    
    // When: 更新变换（级联）
    scene.update_transforms();
    
    // Then: 子节点的世界坐标应该是累积的
    let child_world_transform = scene.get_world_transform(child);
    let point = Vec2::new(0.0, 0.0);
    let world_pos = child_world_transform.to_matrix() * point.extend(1.0);
    
    assert_eq!(world_pos.truncate(), Vec2::new(150.0, 150.0));
}
