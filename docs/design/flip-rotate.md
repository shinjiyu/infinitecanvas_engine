# 翻转与 90° 旋转

选中元素后，绕选区中心做左右/上下镜像，或顺时针/逆时针转 90°。只改 `transform`。

```text
选择
  │
  ▼
可见、未锁定、选中子树的根（与方向键同一批目标）
  │
  ├─ 一个目标：绕该元素世界包围盒中心
  └─ 多个目标：绕这些包围盒并集的中心
        │
        ├─ 水平翻转：平移反射，rotation 取反，scale.x 取反
        ├─ 垂直翻转：平移反射，rotation 取反，scale.y 取反
        └─ ±90°：平移绕中心转动，rotation ±π/2，scale 不动
              │
              ▼
        set_world_transform（组根带动子孙）── mark_dirty，一条历史
```

选中组时命令里只有组根，子元素仍挂在组上。空选、锁定或隐藏不入栈。

图片（#32）默认缩放锁宽高比。翻转不改 `size`，只否定一个缩放分量，`|scale.x| / |scale.y|` 保持不变，显示宽高比仍是锁定后的比例。

这四条键在 `www/shortcuts.js` 的 `SHORTCUTS` 里，`?` 帮助面板和按键分发读同一张表：`Shift+H`、`Shift+V`、`Shift+R`、`Shift+Alt+R`。不带 Shift 的 H / V / R 仍是工具键。带 Ctrl 或 ⌘ 不翻转、不旋转。Demo 工具栏和属性面板另有同样的四个按钮。
