# 顶点缓存与脏标记

世界空间顶点只在元素变化时重生成。视口平移/缩放只更新投影 uniform。

```text
Scene.mark_dirty(id) ──► VertexCache.sync
        │                      │
        │ 无脏元素              ├─ 增量 GpuVertexWrite ──► queue.write_buffer
        │                      └─ geometry_unchanged ──► 只写 64 字节 uniform
        └─ 增删元素 ──► 按 z-index 重排一次，整段上传
```

| 元素 | 缓冲 | 说明 |
|------|------|------|
| 投影 | fill（三角形） | 形状、直线、路径、文本、图片在自己的填充之前写入。关闭时不生成顶点。多边形和星形用局部顶点环 |
| 矩形 / 圆形 / 多边形填充 | fill（三角形） | 纯色矩形 6 个顶点，圆和多边形是扇形。线性渐变按色标切条，径向是射线近似；星形径向仍用扇形顶点色。颜色 alpha 乘 `ElementStyle::opacity`。描边不参与渐变 |
| 矩形 / 圆形 / 多边形粗描边 | fill（三角形带） | 线宽大于 0 时跟在填充后面。虚线、线帽、线结和实线斜接都在这里 |
| 矩形 / 圆形 / 多边形细描边 | stroke（线段） | 线宽小于等于 0 时不生成。有虚线时只保留图案里的开区间 |
| 直线 / 箭头 / 自由画笔 | fill（三角形） | 与旧收集器相同，三角形带。投影是描边胶囊（加箭头三角形） |
| 图片 | textured | 按纹理合并相邻绘制，先画纯色底。投影四边形在 fill 缓冲，按该元素的 z 与其它填充一起画 |
| 文本 | textured | 不画纯色底，避免挡住透明字形。投影是局部包围盒四边形，同样进 fill 缓冲 |
| 组 | 无 | 组本身不生成顶点。平移、旋转、缩放或显隐时，子树里的叶子（含文本）被标脏并重写 |

几何修改（平移、旋转、缩放、端点、箭头、采样点、透明度、填充/描边/线宽/虚线/线帽/线结、渐变种类和色标、矩形圆角、多边形边数或星形内径、投影、混合模式、文本内容或光栅结果、图片移动或变换，以及组变换）必须调用 `Scene::mark_dirty`。混合模式不进顶点色，但会写进绘制区间；`SetStyle` 会标记脏，下一帧同步槽位。只改视口不要调用。`SetStyle` 的执行和撤销会标记受影响的元素。矩形圆角、多边形边数、渐变、投影和填充、描边走同一条命令。文本改字号、颜色或描边时丢掉光栅，下一帧重画；只改不透明度、投影或混合模式时保留纹理，用 tint。投影画在元素自己的填充前面，不改变跨元素的 z 顺序。文本和图片的纹理通道仍在全部填充之后，所以它们的投影先出现在填充缓冲里。网格画在填充之前，投影盖在网格上、元素本体下。全部可见叶子都是 `normal` 时仍按填充、描边、纹理批量绘制；只要有非 `normal` 叶子，就按 z 逐叶子合成。渐变已经烤进填充顶点，合成时跟填充一起进叶子层。文本的创建、改内容、撤销/重做和 `commit_text_raster` 都会标记。图片走同一条脏队列：移动、变换或不透明度只重生成那一个元素的纹理四边形。组的 `translate_element` / `set_world_transform` / `set_visible` 会把整棵子树入队，文本和图片的纹理四边形跟着重写。隐藏的组在重写时不再输出子孙三角形。

`Scene::geometry_epoch` 在增删元素和每次 `mark_dirty` 时递增，小地图用它决定要不要重画缩略图。视口平移/缩放不递增。

变换手柄写完整 `Transform`。实时拖动（含多选和取消）在应用变换列表时标记脏；`TransformElementsCommand` 的执行与撤销同样标记，顶点才会重生成。

`dirty`、结构版本和脏队列不写入场景 JSON。`import_json` 让缓存失效，下一帧整表重建并全量上传。
