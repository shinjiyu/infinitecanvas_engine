# 多选对齐与分布

选中至少两个元素后，按世界包围盒平移。选中组时用组的世界包围盒，只移动组根，子元素仍挂在组上。

```text
选择
  │
  ▼
可见、未锁定、选中子树的根（与方向键同一批目标）
  │
  ├─ 对齐（≥2）── 贴齐这些包围盒并集的边或中心
  └─ 分布（≥3）── 按左缘或上缘排序，两端不动，相邻间隙相等
        │
        ▼
translate_element（只加 translation）── mark_dirty ── 一条历史
```

| 操作 | 模式 | 结果 |
| --- | --- | --- |
| 对齐 | `left` / `center` / `right` | 水平边或水平中心共线 |
| 对齐 | `top` / `middle` / `bottom` | 垂直边或垂直中心共线。Y 向下 |
| 分布 | `horizontal` | 左右两端不动，中间水平间隙相等 |
| 分布 | `vertical` | 上下两端不动，中间垂直间隙相等 |

单选、空选、锁定或隐藏后不足数量时不入栈。已经贴齐或间隙已经相等也不入栈。旋转和缩放不动。拖拽吸附仍只在指针拖动里生效。
