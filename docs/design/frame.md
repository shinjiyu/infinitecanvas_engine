# 画板（Frame / Artboard）

画板是带名字的轴对齐矩形容器。子元素仍用 `parent` / `children`，和组同一套树。画板自己的宽高不随子元素重算。

```text
F 拖拽 ──► AddElementCommand（Frame）
                │
                ├─ 子元素优先命中；Alt 选中画板
                ├─ 手柄缩放走 TransformElementsCommand（子元素跟着变）
                └─ 重命名 / 移入画板各是一条命令
导出 PNG / SVG ──► 世界包围盒，超出部分裁掉
画布绘制 ──► 不裁剪（顶点缓存没有按元素裁剪）
```

## 数据

| 字段 | 缺省 | 作用 |
| --- | --- | --- |
| `name` | `"Frame"` | 图层面板和属性面板上的名字 |
| `size` | 100×100 | 局部宽高。中心是 `transform.translation` |
| `style` | 浅底 + 细描边 | 填充和描边。投影走 `ElementStyle.shadow`。图层模糊走 `blur_radius` |
| `children` | `[]` | 直接子元素，顺序即大纲顺序 |

JSON 类型是 `frame`。上面四个字段都 `serde(default)`，旧文档没有画板仍然能读。

## 交互

- 工具栏和 `F` 进入画板工具。拖拽创建，过小的拖拽不入栈。
- 点在子元素上选中子元素。点在画板空白处选中画板。按住 Alt 时，光标下最上层的画板优先。
- 缩放用现有变换手柄：改的是缩放，局部 `size` 不变，世界包围盒是 `size * scale`。子元素跟着重定基。
- 双击画板空白处，或属性面板里的名称，调用 `rename_frame`。名称没变、或目标不是画板，不入栈。
- 移入画板走 `reparent_into_frame`。空选择、已经在这块画板里、或没有元素移动，不入栈。
- 解组只解散 `Group`，不解散画板。

## 导出

`export_frame_png` / `export_frame_svg` 的区域就是画板的轴对齐世界包围盒，没有额外留白。只画这块画板和它的子孙，压在上面但不是子元素的图形不画进去。空画板仍导出矩形尺寸。

`selectionOnly` 在选区根全是画板时同样裁到这些包围盒的并集。混有其它根元素时仍用原来的外扩选区。

画板自己的图层模糊如果超出世界包围盒，PNG 和 SVG 导出都会裁掉这段光晕。画布绘制不按画板裁剪。
