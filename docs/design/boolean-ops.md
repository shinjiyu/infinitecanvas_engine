# 布尔运算

选中至少两个闭合叶子后，可以并集、相减、交集或异或。结果是一条路径，一次撤销还原操作数。

```text
工具栏 / 属性面板（无快捷键）
        │
        ▼
boolean_targets ── 可见、未锁定的矩形 / 圆 / 多边形 / 闭合路径
        │  少于 2 个：不入栈
        ▼
世界坐标多边形 ── i_overlay（NonZero）
        │
        ├─ Union / Intersect / XOR：全部操作数，顺序无关
        └─ Subtract：最上层 − 其余（前 − 后）
        │
        ▼
Path.shapes 替换操作数
        ├─ 样式、z_index 取最上层
        └─ 最上层在组或画板里时，结果留在该父节点的同一位置
```

## 结果

| 字段 | 含义 |
| --- | --- |
| type | 仍是 `path`。不新增元素种类 |
| shapes | 填充轮廓。每项的第一条环是外轮廓，其余是孔。局部坐标，不重复首点 |
| points | 布尔结果为空。自由画笔仍只用 `points` |
| style | 复制最上层的整份样式：填充、描边、线宽、不透明度、线型、线帽、线结、投影，以及 `fill_kind` / `fill_stops` / `fill_angle` / `fill_center` / `fill_radius`。这些渐变字段都是 `serde(default)`，和 `shapes` 一样，旧文档缺省仍有效 |

`shapes` 缺省为空，空时不写入 JSON。没有布尔结果的旧文档照旧打开。

叠放用 `(z_index, id)`，较大者在上。相减与选中顺序无关。

父节点只跟着最上层操作数走。其他组或画板里的操作数会被摘走，容器本身留下。不重写场景里其余元素的 `z_index`。

画板不是操作数。结果仍是叶子 `Path`，挂在最上层操作数原来的父节点上（组或画板）。不改画板的名称和尺寸，也不改子元素优先命中：点在结果上选中路径，按住 Alt 仍选中画板。投影跟样式一起从最上层复制；自由画笔的笔画投影不变，填充结果沿外轮廓投影。

渐变也跟整份样式走。线性填充按色标切开每张耳切三角形；径向在顶点取样。SVG 仍是一条 `fill-rule="evenodd"` 路径，渐变定义写在该元素的 `defs` 里。描边保持纯色。
