# WASM 与 JS 接口设计指南

> 针对无限画布等复杂应用的接口粒度设计
> 平衡性能、易用性和可维护性

---

## 🎯 核心原则

### WASM ↔ JS 调用的性能成本

```
单次跨界调用开销: ~0.5-2 微秒

场景对比:
1. 频繁小调用 (❌ 反模式)
   - 1000 次调用 = 0.5-2ms 开销
   - 如果每帧 (16ms) 调用 1000 次 = 3-12% CPU 浪费

2. 批量大调用 (✅ 推荐)
   - 1 次调用传递 1000 个元素 = 0.5-2μs 开销
   - CPU 开销可忽略不计
```

### 接口设计三原则

```
1. 批量优于频繁
   ✅ 一次传递多个元素
   ❌ 每个元素单独调用

2. 粗粒度优于细粒度
   ✅ 高层业务操作
   ❌ 底层细节暴露

3. 数据优于回调
   ✅ 返回结果数组
   ❌ 频繁回调 JS
```

### 方案 3: 粗粒度接口（✅ 推荐 - 高性能）

#### 接口设计

```rust
// WASM 侧 - 粗粒度，批量操作
use serde::{Deserialize, Serialize};

#[derive(Serialize, Deserialize)]
pub struct Element {
    pub element_type: String,  // "rectangle", "circle", "path"
    pub x: f32,
    pub y: f32,
    pub width: Option<f32>,
    pub height: Option<f32>,
    pub radius: Option<f32>,
    pub fill_color: Option<String>,
    pub stroke_color: Option<String>,
    pub stroke_width: Option<f32>,
}

#[derive(Serialize, Deserialize)]
pub struct BatchOperations {
    pub add: Vec<Element>,
    pub update: Vec<(String, Element)>,
    pub remove: Vec<String>,
}

#[wasm_bindgen]
impl InfiniteCanvas {
    /// 批量添加元素
    #[wasm_bindgen]
    pub fn add_elements(&mut self, elements_json: &str) -> Result<String, JsValue> {
        let elements: Vec<Element> = serde_json::from_str(elements_json)
            .map_err(|e| JsValue::from_str(&e.to_string()))?;
        
        let mut ids = Vec::new();
        
        for element in elements {
            let node = match element.element_type.as_str() {
                "rectangle" => Node::Shape(ShapeNode::rectangle(
                    element.x,
                    element.y,
                    element.width.unwrap_or(0.0),
                    element.height.unwrap_or(0.0),
                )),
                "circle" => Node::Shape(ShapeNode::circle(
                    element.x,
                    element.y,
                    element.radius.unwrap_or(0.0),
                )),
                _ => continue,
            };
            
            let id = self.scene.add_node(self.root, node);
            ids.push(id.to_string());
        }
        
        serde_json::to_string(&ids)
            .map_err(|e| JsValue::from_str(&e.to_string()))
    }
    
    /// 批量操作（添加、更新、删除）
    #[wasm_bindgen]
    pub fn batch_operations(&mut self, operations_json: &str) -> Result<String, JsValue> {
        let ops: BatchOperations = serde_json::from_str(operations_json)
            .map_err(|e| JsValue::from_str(&e.to_string()))?;
        
        let mut results = BatchResults {
            added_ids: Vec::new(),
            updated_count: 0,
            removed_count: 0,
        };
        
        // 批量添加
        for element in ops.add {
            let id = self.add_single_element(element);
            results.added_ids.push(id.to_string());
        }
        
        // 批量更新
        for (id, element) in ops.update {
            if self.update_single_element(&id, element) {
                results.updated_count += 1;
            }
        }
        
        // 批量删除
        for id in ops.remove {
            if self.remove_single_element(&id) {
                results.removed_count += 1;
            }
        }
        
        serde_json::to_string(&results)
            .map_err(|e| JsValue::from_str(&e.to_string()))
    }
    
    /// 查询可见元素（返回元素数据，不是 ID）
    #[wasm_bindgen]
    pub fn get_visible_elements(&self) -> Result<String, JsValue> {
        let visible_bounds = self.viewport.get_visible_bounds();
        let visible_node_ids = self.scene.query_viewport(&visible_bounds);
        
        let mut elements = Vec::new();
        
        for node_id in visible_node_ids {
            if let Some(element_data) = self.get_element_data(node_id) {
                elements.push(element_data);
            }
        }
        
        serde_json::to_string(&elements)
            .map_err(|e| JsValue::from_str(&e.to_string()))
    }
}
```

#### TypeScript 封装层

```typescript
// 在 JS/TS 侧提供友好的封装
export class InfiniteCanvasWrapper {
  private wasmCanvas: InfiniteCanvas;
  private pendingOperations: Operation[] = [];
  private flushTimer: number | null = null;
  
  constructor(canvas: HTMLCanvasElement) {
    this.wasmCanvas = new InfiniteCanvas(canvas);
  }
  
  // === 简单 API（自动批量化）===
  
  addRectangle(x: number, y: number, w: number, h: number, fill: string): string {
    // 小批量场景：直接调用
    if (this.pendingOperations.length === 0) {
      return this.wasmCanvas.add_rectangle(x, y, w, h, fill);
    }
    
    // 大批量场景：累积后批量提交
    const tempId = generateTempId();
    this.pendingOperations.push({
      type: 'add',
      elementType: 'rectangle',
      props: { x, y, width: w, height: h, fill_color: fill },
      tempId,
    });
    
    this.scheduleFlush();
    return tempId;
  }
  
  // === 批量 API ===
  
  addElements(elements: Element[]): string[] {
    const json = JSON.stringify(elements);
    const result = this.wasmCanvas.add_elements(json);
    return JSON.parse(result);
  }
  
  // === 自动批量化机制 ===
  
  private scheduleFlush() {
    if (this.flushTimer !== null) return;
    
    // 使用 requestAnimationFrame 或 setTimeout
    this.flushTimer = requestAnimationFrame(() => {
      this.flush();
    });
  }
  
  private flush() {
    if (this.pendingOperations.length === 0) return;
    
    const operations = {
      add: this.pendingOperations.filter(op => op.type === 'add'),
      update: this.pendingOperations.filter(op => op.type === 'update'),
      remove: this.pendingOperations.filter(op => op.type === 'remove'),
    };
    
    const json = JSON.stringify(operations);
    const results = JSON.parse(this.wasmCanvas.batch_operations(json));
    
    // 更新临时 ID 到真实 ID 的映射
    this.updateIdMappings(results);
    
    this.pendingOperations = [];
    this.flushTimer = null;
  }
  
  // === 强制立即执行 ===
  
  flushNow() {
    if (this.flushTimer !== null) {
      cancelAnimationFrame(this.flushTimer);
      this.flushTimer = null;
    }
    this.flush();
  }
}
```

| 操作 | 推荐方案 | 理由 |
|------|---------|------|

| 视口平移 | WASM 内部 | 不跨界，WASM 直接重绘 |

## 💡 最佳实践建议

### 1. 数据流向设计

```
┌─────────────────┐
│   JavaScript    │  应用逻辑、事件处理
└────────┬────────┘
         │ 高层 API（封装层）
         │ - 自动批量化
         │ - 类型安全
         ↓
┌─────────────────┐
│  WASM 接口层    │  粗粒度批量操作
│  (wasm-bindgen) │  - JSON 序列化
└────────┬────────┘  - 批量处理
         │
         ↓
┌─────────────────┐
│  WASM 核心层    │  渲染引擎、场景图
│   (纯 Rust)     │  - 高性能计算
└─────────────────┘  - GPU 渲染
```

### 2. 何时使用哪种粒度

```typescript
// ✅ 使用简单 API（中粒度）
canvas.addRect(0, 0, 100, 100);  // 单个元素
canvas.removeElement(id);         // 单个操作

// ✅ 使用批量 API（粗粒度）
canvas.addElements([...]);        // > 10 个元素
canvas.batchUpdate([...]);        // > 10 个更新

// ✅ 让 WASM 控制（最高性能）
canvas.render();                  // 渲染循环在 WASM
canvas.pan(dx, dy);              // 视口操作在 WASM
```

pub fn get_elements_bounds(&self, ids: Vec<String>) -> Vec<f32> {
    // 返回扁平数组 [x1,y1,w1,h1, x2,y2,w2,h2, ...]
    let mut result = Vec::new();
    for id in ids {
        if let Some(bounds) = self.get_bounds(&id) {
            result.extend_from_slice(&[bounds.x, bounds.y, bounds.width, bounds.height]);
        }
    }
    result
}

## 📝 总结

### 推荐方案

**混合粒度接口（方案 4）**

```
粗粒度批量操作（WASM 层）
    ↕
中粒度常用操作（WASM 层）
    ↕
自动批量化封装（TS 层）
    ↕
简单友好 API（应用层）
```

### 关键原则

1. ✅ **批量优于频繁** - 累积后一次提交
2. ✅ **粗粒度优于细粒度** - 高层操作而非底层细节
3. ✅ **数据优于回调** - 返回结果而非回调 JS
4. ✅ **让 WASM 控制渲染循环** - 减少跨界调用
5. ✅ **提供多层 API** - 简单场景简单用，复杂场景高性能

### 性能目标

```
单次跨界调用: < 2μs
每帧跨界调用: < 10 次
批量操作 10000 元素: < 5ms
总跨界开销: < 5% CPU 时间
```
