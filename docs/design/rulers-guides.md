# 标尺与手动参考线

顶边和左边各一条标尺。刻度是世界单位，主步长按当前缩放收成 1/2/5×10^n，屏幕上大约 80px 一格。平移和缩放后刻度重算。

```text
顶标尺（刻度 = 世界 x）──向下拖──▶ 水平参考线（固定 y）
左标尺（刻度 = 世界 y）──向右拖──▶ 垂直参考线（固定 x）
                                         │
                                         ▼
                               Scene.guides（JSON guides[]）
                                         │
                    ┌────────────────────┼────────────────────┐
                    ▼                    ▼                    ▼
            拖拽平移包围盒          缩放中的元素边         PNG / SVG
         与元素边缘同一次取最近      指针按斜率修正        默认不画
```

参考线 id 和元素 id 分开。拖回对应标尺、双击或 Delete（参考线选中时）删除，进撤销栈。角上不拖线。

吸附阈值就是 #14 的屏幕像素（默认 6）。关掉吸附，或用 G 隐藏标尺，参考线都不参与。隐藏不删数据。

`G` 登记在 `www/shortcuts.js`，帮助面板列出「显示或隐藏标尺和参考线」。`Ctrl+G` 仍是成组。Demo 在吸附一组里还有「标尺参考线」按钮。
